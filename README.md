# Finance Tracker
A RESTful backend application for managing finances, built with Java and Spring Boot

## Development Steps
- Rest API with Spring Boot
- Database design with PostgreSQL
- Spring Data JPA and entity relationships
- User registration and authentication with Spring Security
- Transaction management and categories
- Monthly budgets
- Monthly financial analytics
- Docker containerization and Docker Compose
- AWS EC2 deployment
- CI/CD with GitHub Actions
- More to follow

## What I learned
- Relational database design and entity relationships
- Authentication and authorization with Spring Security
- Docker images, containers, networking and volumes
- Cloud infrastructure and deployment with AWS
- CI/CD automation
